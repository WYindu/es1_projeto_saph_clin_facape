## Pré-condições

- acolhimento em contato com o solicitante.

## Pós-condições

- **Sucesso:** um chamado registrado e pronto para a classificação.
- **Falha:** um chamado cancelado.

## Fluxo principal

1. O Acolhimento informa os dados minimos (identidade solicitante) para o TASI.
2. O TASI inicia a chamada.
3. O sistema registra a identidade do soliciatante.
4. O TASI solicita localização.
5. O sistema registra a localização.
6. O sistema eleje um MedicoRegulador disponivel.
7. o sistema envia o chamado para o MedicoRegulador para classificação.


> Escreva no presente do indicativo, uma ação por passo, sem detalhe de interface.

## Fluxos alternativos

### FA-01 — identidade indisponivel

- **Condição:** identidade do solicitante não disponivel.
- **Passos:** 
1. O sistema registra a identidade como anonimo. 
- **Reconvergência:** retorna ao passo 4 do fluxo principal.

### FA-02 — solicitação de dados adicionais

- **Condição:** solicitante se mostra cooperativo e sem agravante claro.
- **Passos:** 
1. O TASI solicita tipo sanguíneo.
2. O sistema registra tipo sanguíneo.
3. O TASI solicida mais detalhes da queixa principal.
4. O sistema complementa a queixa principal.
5. O TASI solicita queixas secundaria.
6. o sitema registra queixas secundaria.
- **Reconvergência:** retorna ao passo 5 do fluxo principal.

## Fluxos de exceção

### FE-01 — localização indisponivel

- **Condição:** localização não informada
- **Passos:** 
1. O sistema cancela a chamada  
- **Estado final:** registra uma chamada cancelada.
