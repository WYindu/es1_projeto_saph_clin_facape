# UC-G01-01 — Registrar Chamado

## Identificação

| Campo | Valor |
| --- | --- |
| **ID** | UC-G01-01 |
| **Módulo** | G01 - Registrar Chamado |
| **Ator primário** | TASI |
| **Atores secundários** | Solicitante |
| **Objetivo** | um chamado registrado pronta para a classificação |
| **Requisitos rastreados** | [RF-G01-01](../matriz-rastreabilidade.md#Requisitos-funcionais), [RF-G01-04](../matriz-rastreabilidade.md#Requisitos-funcionais) |
| **Prioridade** | essencial |

## Pré-condições

- acolhimento em contato com o solicitante.

## Pós-condições

- **Sucesso:** o chamado registrado e pronto para a classificação.
- **Falha:** o chamado cancelado.

## Fluxo principal

1. O Acolhimento informa os dados minimos (identidade solicitante, localização, queixa principal) para o TASI.
2. O TASI inicia o chamado.
3. O TASI registra no sistema a identidade do solicitante.
4. O TASI registra no sistema a localização do solicitante.
5. O TASI registra no sistema a queixa principal.
6. O TASI sinaliza fim da criação do chamado.
7. O sistema verifica chamada duplicada.
8. O sistema envia o chamado finalizado para classificação.

## Fluxos alternativos

### FA-01 — identidade indisponivel

- **Condição:** identidade do solicitante não disponivel.
- **Passos:** 
1. O sistema registra a identidade como anonimo. 
- **Reconvergência:** retorna ao passo 4 do fluxo principal.

### FA-02 — solicitação de dados adicionais

- **Condição:** solicitante se mostra cooperativo e sem agravante claro.
- **Passos:** 
1. O TASI solicita tipo sanguíneo.
2. O TASI registra no sistema registra tipo sanguíneo.
3. O TASI solicida mais detalhes da queixa principal.
4. O TASI registra no sistema complementos a queixa principal.
5. O TASI solicita queixas secundaria.
6. O TASI registra no sistema queixas secundaria.
- **Reconvergência:** retorna ao passo 6 do fluxo principal.

### FA-03 — possivel chamada duplicada

- **Condição:** o sistema identificou a chamada como possivel duplicata.
- **Passos:** 
1. O sistema elege um TASI livre.
2. O sistema envia as informações para o TASI eleito.
3. O TASI analiza as informações entrege.
4. O TASI informa duplicidade ou não.
- **Reconvergência:** retorna ao passo 8 do fluxo principal.

## Fluxos de exceção

### FE-01 — localização indisponivel

- **Condição:** localização não informada
- **Passos:** 
1. O sistema cancela o chamado <<extend>> uc-g01-04 (cancelamento).  
- **Estado final:** registra um chamado cancelado.

### FE-02 — queixa indisponivel

- **Condição:** queixa não informada
- **Passos:** 
1. O sistema cancela o chamado <<extend>> uc-g01-04 (cancelamento).
- **Estado final:** registra um chamado cancelado.

### FE-03 — chamado doplicado

- **Condição:** chamado identificado como duplicado.
- **Passos:** 
1. O sistema inicia o cancelamento. <<extend>> uc-g01-04 (cancelamento).
- **Estado final:** registra um chamado cancelado.

## Critérios de aceite

- [ ] chamado identificada unicamente.
- [ ] chamado registrada.
- [ ] chamado com todos os dados minimos registrado.
- [ ] chamada identificada como duplicata.
- [ ] chamada cancelada em caso de duplicata.
- [ ] chamada cancelada em caso de falta de informação.
